# Scope: every Leakshield feature except firmware update; no other RGB devices; no other Aqua Computer devices in v1

nicecooling covers every Leakshield feature in aquasuite, including display pages, Software sensors and RGBpx lighting, except the firmware update. Firmware images ship inside aquasuite, and a failed flash can make the device unusable, so firmware updates stay in aquasuite in the VM. The Board RGB controller (ASUS AURA) and the Corsair Lighting Node PRO stay out, because OpenRGB covers them. The GPU is an Input only: its fan stays with the amdgpu driver. Other Aqua Computer devices are out of version 1: nicecooling has no real hardware to test their write path. Their sensors still appear through generic hwmon discovery when the kernel driver exposes them.
