# Scope: every Leakshield feature; no other RGB devices; no other Aqua Computer devices in v1

nicecooling covers every Leakshield feature in aquasuite, including display pages, Software sensors, RGBpx lighting and the firmware update. The firmware update is a separate change, `add-leakshield-firmware-update`, after version 1. nicecooling ships no firmware: it reads the image from the aquasuite package that the user downloaded, because the images belong to Aqua Computer. A failed flash leaves the device in its bootloader, and a second flash from the bootloader recovered it on the reference device, so the daemon can resume a flash. The Board RGB controller (ASUS AURA) and the Corsair Lighting Node PRO stay out, because OpenRGB covers them. The GPU is an Input only: its fan stays with the amdgpu driver. Other Aqua Computer devices are out of version 1: nicecooling has no real hardware to test their write path. Their sensors still appear through generic hwmon discovery when the kernel driver exposes them.
