# Terms of the app text

One term has one translation in a language. This table is the source for `crates/nicecooling/locales/<code>.yml`. A new text uses a term of this table. A new term gets a row in every language first.

A term that Italian keeps in English stays in English in German. A term that Italian translates has a German word. Product names (nicecooling, Leakshield, aquasuite), the Mode names SHIELD, MONITOR and RELEASE, units, key names and identifiers in backticks stay as they are in every language.
