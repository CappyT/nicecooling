# Tasks

In this file, a Dashboard is a page that the user builds, and a Tile is one box of it. `design.md` has the decisions P1 to P15. `specs/dashboards/spec.md` has the requirements.

Paths are relative to the repository root. Each path in a task has the marker "create" or "modify". A test name in a task is a test that the task creates. A test marked "(existing)" exists already and must still pass. Each test name belongs to one task only.

This change touches the app crate `crates/nicecooling` only. No task changes a file under `crates/nicecoolingd`, `crates/nicecooling-api`, `crates/nicecooling-core` or `crates/nicecooling-protocol`, and no task changes `docs/api.md`. This change does not depend on `add-node-graph`. Where both changes edit one file, the task says what to do.

A task marked MANUAL needs a person on the reference desktop. The person follows a procedure file in `docs/hardware-checks/`. The file lists steps, the result that the person sees, and one pass or fail line per step. A MANUAL task passes when every step has a pass line.

Each section ends with a checkpoint task. The checkpoint command is:
`cargo test --workspace && cargo clippy --workspace --all-targets -- -D warnings && cargo fmt --all --check && python3 -I tools/re/check-identifiers.py && openspec validate add-dashboard-pages --strict`.

Strings of the app go in the four locale files `crates/nicecooling/locales/en.yml`, `it.yml`, `de.yml` and `fr.yml`, under the new top-level key `dashboards` and the key `nav.dashboards`, with the task that uses them. The four files keep the same key order. The tests `every_key_has_every_language`, `every_language_keeps_the_order_of_the_keys` and `every_key_used_in_source_exists` in `crates/nicecooling/tests/i18n.rs` (existing) check them. A text uses the terms of `docs/i18n-terms.md`.

A new integration test file of the app is under `crates/nicecooling/tests/` and starts with `mod support;`. The fixture `full()` of `crates/nicecooling/tests/support/fixtures.rs` gives the Loop "Main loop" with a Leakshield, the flow `loop_1_flow`, the water temperature `nct6798_temp1`, the Pump channel "Waterpump" with the speed sensor `nct6798_fan6`, and the Channel "Chassis Fan 1" with no speed sensor.
