# Tasks

In this file, the store is `history.db`, the service is the history service thread, and a request is a message from the window to the service (design H5). Series, Sample, Minute row, View and Note are the terms of the design table "Terms".

Paths are relative to the repository root. Each path in a task has the marker "create" or "modify". A test name in a task is a test that the task creates. A test marked "(existing)" exists already and must still pass. A test marked "(existing, modified)" exists and the task changes it. Each test name belongs to one task only.

This change depends on `add-nicecooling-v1`: its history store (`crates/nicecooling/src/history/`), its History, Settings and Sensors screens and its app settings (`docs/storage.md`). All code of this change is in `crates/nicecooling`. No task changes `crates/nicecoolingd`, `crates/nicecooling-api` or `crates/nicecooling-core`.

A task marked MANUAL needs a person on the reference desktop. The person follows a procedure file in `docs/hardware-checks/`. The file lists steps, the result that the person sees, and one pass or fail line per step. A MANUAL task passes when every step has a pass line. A check that a container can run is automated.

Each section ends with a checkpoint task. The checkpoint command is:
`cargo test --workspace && cargo clippy --workspace --all-targets -- -D warnings && cargo fmt --all --check && python3 -I tools/re/check-identifiers.py && openspec validate add-history-export --strict`.

Strings of the app go in `crates/nicecooling/locales/en.yml`, `crates/nicecooling/locales/it.yml`, `crates/nicecooling/locales/de.yml` and `crates/nicecooling/locales/fr.yml` with the task that uses them. "The four locale files" in a task means these four files, with the marker "modify". The tests `every_key_has_every_language`, `every_language_keeps_the_order_of_the_keys` and `every_key_used_in_source_exists` in `crates/nicecooling/tests/i18n.rs` (existing) check them.

The logic of the store is in `crates/nicecooling/src/history/` and has no GPUI type. A screen model is in `crates/nicecooling/src/screens/<name>.rs` and its view in `<name>_view.rs`. A new integration test file of the app is under `crates/nicecooling/tests/`. A test of the store uses a database in a scratch directory or in memory, and a simulated time.
